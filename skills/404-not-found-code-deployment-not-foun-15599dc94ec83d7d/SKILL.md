Copy the deployment id exactly from the original deploy output or dashboard URL and retry the lookup with that full value.

Confirm which account, team, or workspace your CLI is signed in to, and compare it with where the deployment was created.

List recent deployments for the current project and look for the one you expect.

Check the local project link or config file in this directory and confirm it points at the intended project.

If the deployment was just created, wait a short time and retry the lookup once.

If the list is empty and the deploy command reported success, re-run the deploy and capture its full output, including the project and deployment id it prints.
