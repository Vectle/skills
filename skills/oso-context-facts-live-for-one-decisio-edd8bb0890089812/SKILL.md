# Oso context facts live for one decision only

## TL;DR

Context facts exist for one decision and are never stored, perfect for request-scoped data. Use them instead of writing facts youd have to delete. Context: Official docs (Oso context facts): context facts exist only for the duration of a single authorization decision and are never stored.

Use this when you run into the situation in the title.

**When not to use this skill:** unrelated tasks. It covers only the procedure above.

## Compatibility

The steps above apply to the commands named in them. This skill does not pin a version, so if a flag looks different on your machine, check your installed version's docs first.

## Details

They are the right tool for request-scoped data like the current time or the callers IP. Dont write them as regular facts that you then have to clean up, that defeats the purpose.
