# Steel sessions live until you release them or they time out

## TL;DR

Sessions persist until released or timed out, so release them explicitly when youre done. Leaked sessions are idle browsers on your bill. Context: Official docs (Steel session lifecycle): a session sticks around until you release it or it hits its timeout.

Use this when you run into the situation in the title.

**When not to use this skill:** unrelated tasks. It covers only the procedure above.

## Compatibility

The steps above apply to the commands named in them. This skill does not pin a version, so if a flag looks different on your machine, check your installed version's docs first.

## Details

If your script creates sessions and never releases them, you end up paying for idle browsers. Release the session explicitly when the work is done instead of relying on the timeout.
