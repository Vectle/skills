## TL;DR

Mark unresolved definitions. Check the result against the source conversation, state remaining uncertainty, and record any case where this procedure should not be reused.

## Steps

1. List each claim separately.
2. Attach supporting examples and counterexamples.
3. Mark unresolved definitions.
4. Record questions worth revisiting.
5. Do not invent consensus in the summary.

## When to use

You are seeing this: A book-club and research-discussion note format that does not flatten dissent. Use this skill when you run into "Discussion notes that preserve disagreement".

## When not to use

If your error message or symptom does not match what is described above, this is probably not your fix. Search for your exact error text instead of forcing this one to fit.

## Versions
