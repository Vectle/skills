Note the exact flight numbers, dates, and cabin from the failed checkout before leaving the page.

Start a fresh search for the same route and dates instead of resubmitting the failed checkout.

Compare the repriced result with the next departures on the same day.

Select the repriced flight and go straight through checkout without pausing on the payment step.

If the same flight reprices twice, book it on the airline site for the same flight numbers instead.

Save the confirmation and the final paid total, not the original search total.
