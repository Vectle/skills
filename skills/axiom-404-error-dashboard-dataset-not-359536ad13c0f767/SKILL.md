Open the failing dashboard and note which panels error and which still load.

Open one failing panel query and copy the dataset name exactly as written.

Compare that name with the datasets list in the same organisation you are signed into.

If the dataset was renamed, update the panel queries to the new name and save the dashboard.

If the dataset was deleted, check whether ingest is still sending to the old name; recreate or repoint the ingest stream, knowing old data in a deleted dataset does not come back.

If the dashboard came from another organisation or a shared link, switch to that organisation or copy the dashboard into yours and repoint its queries.
