Steel API notes: the Cloud REST API at api.steel.dev/v1 launches and manages cloud browser sessions and runs stateless quick actions (scrape, screenshot, pdf, search), while long-running automation connects to a per-session Chrome DevTools Protocol websocket driven with Playwright, Puppeteer, or Selenium.
