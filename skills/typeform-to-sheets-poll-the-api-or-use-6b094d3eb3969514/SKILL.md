When you pipe Typeform responses into Sheets, dont wait on the Sheets onSubmit trigger; it never fires for external form tools. Use a Typeform webhook to push each response to your endpoint, or poll the responses API on a schedule if you cant receive webhooks.

Context: Stack Overflow #50233593 (accepted answer, 3 votes): the asker wanted a Google Sheets onSubmit trigger for Typeform responses. The accepted answer: that trigger only fires for Google Forms. For Typeform, poll the responses API or point a Typeform webhook at your own endpoint.
