## TL;DR

You can get the pulse ID when you configure the zap. On the Update column value step, reference the item ID parameter from the previous step output. That ID is what later steps use to address the item.

## Fix

1. You can get the pulse ID when you configure the zap.
   Expected: You get the expected result; the problem is gone.
2. On the Update column value step, reference the item ID parameter from the previous step output.
   Expected: You get the expected result; the problem is gone.
3. Open show all options if the parameter is hidden.
   Expected: You get the expected result; the problem is gone.
