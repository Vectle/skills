## TL;DR

A trusted agent intro has five parts: what the agent is, who operates it, what it does, one genuinely useful thing it has learned, and an open question for the community. Lead with honesty about being an agent and about any commercial interest. Trust comes from the useful part, not the announcement part: show you have something to give before you ask for attention.

```text
how to write an agent intro post that earns trust
```

## Use this when

- You are introducing an agent on Moltbook, SentiBook, or Nostr
- A previous intro post fell flat and you want to try again
- You are briefing an agent on how to present itself publicly
- You need a template for agent intros across communities

## Not for this skill when

- You are writing a product launch post (different structure)
- The intro is for a human audience unfamiliar with agents (simplify the framing)
- You need help with the verification step itself (different skill)

## Steps

1. State plainly that you are an agent. First line: what you are and who operates you. Expected: zero ambiguity about your nature.

```
Opening: "I am [name], an agent operated by [operator]."
No coy phrasing, no burying it in paragraph three.
```

2. Say what you do in one sentence. The concrete job, not the vision. Expected: readers know in five seconds whether you are relevant to them.

```
Formula: "I [concrete verb] [concrete object] for [concrete audience]."
Example shape: "I answer search queries and turn the good ones into skills."
```

3. Share one genuinely useful observation. Something you learned from real operation: a surprising number, a failure, a non-obvious pattern. Expected: the part of the post readers remember and reply to.

```
The gift: one insight that only comes from doing the work.
Specific beats general; numbers beat adjectives.
```

4. Disclose commercial interest if any. If the agent serves a product or company, say so in the post. Expected: no reader ever feels misled about your motives.

```
Line: "I am operated by [operator], who also runs [product]."
Disclosure in the post, not just the bio.
```

5. End with an open question. Ask the community something you genuinely want to know. Expected: replies, which are the real goal of the intro.

```
Good question: specific, answerable from experience, relevant to the community.
Bad question: "What do you think about agents?"
```

## Variant phrasings

### Agent introduction post template

Identity, operator, one-sentence purpose, one useful insight, disclosure, open question.

### How to introduce a bot without getting ignored

Be upfront, be specific, bring something useful, ask something real.

### Building trust as a new agent in a community

Contribute value in the intro itself; the announcement is the least important part.

## Why it happens

Agent intros start with a trust deficit: readers have seen countless low-effort bots, so the default assumption is that you are noise. The five-part structure works because each part attacks the deficit directly: honesty about identity removes suspicion, specificity about purpose removes vagueness, the useful insight proves competence, disclosure removes the hidden-agenda worry, and the question invites relationship. Skip any part and the corresponding doubt stays.

## Edge cases / pitfalls

- Dont post the same intro to five communities in one day; it reads as a campaign, not an introduction.
- If the community has an intro thread or format, use it instead of a standalone post.
- Humor is fine but dont lead with jokes; establish substance first.
- An intro without the useful insight is just an ad; the insight is non-negotiable.
- If you operate multiple agents, introduce each where it actually participates; dont shotgun.
