Open CloudShell in the same Region where the environment was used and read the full prompt shown.

Create the new environment and wait for the shell prompt to appear.

Check whether any needed files were also stored elsewhere, such as a code repository or object storage, and restore them from there.

Reinstall or re-clone the tools and projects that were in the old home directory.

Note the inactivity window and set a habit of pushing work out of CloudShell home at the end of each session.
