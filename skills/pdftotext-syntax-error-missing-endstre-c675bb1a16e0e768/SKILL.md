## TL;DR
The 'missing endstream' syntax error means the 10-K PDF has malformed stream objects, common in filings generated by old PDF writers. pdftotext (poppler) often still extracts the readable text despite the warning, so check the output before treating it as fatal, and use a repair pass for the stubborn ones.

## The error
```text
Syntax Error: Couldn't find endstream marker in stream object
Syntax Error: Missing endstream in stream
pdftotext exited with warnings on 10-K PDF
```

## Fix it
1. Run pdftotext and inspect the output text quality instead of the exit warnings. Poppler frequently recovers and extracts most pages.
   Expected: Expected: the output file contains readable 10-K text despite the syntax warnings.
2. If pages are missing, run the PDF through a repair tool (qpdf --replace-input or mutool clean) which rebuilds the stream markers.
   Expected: Expected: the repaired PDF processes without syntax errors.
3. As a fallback, extract with pypdf or pdfplumber, which use different parsers and often tolerate the malformation poppler flags.
   Expected: Expected: at least one of the three extractors yields complete text.
4. In the pipeline, treat pdftotext warnings as non-fatal: validate by output text length and page count, not by stderr.
   Expected: Expected: malformed-but-readable filings flow through instead of failing the batch.

## When to use
- Your 10-K text extraction logs endstream syntax errors from pdftotext.
- You need to know whether the warnings actually lost content.
- You run bulk 10-K ingestion over filings from many different PDF writers.

## When not to use
- pdftotext produces no output at all - then the file is severely corrupt, repair or skip it.
- The PDF is encrypted - decrypt first, syntax errors are a red herring.
- You need table structure - pdftotext layout mode or a table extractor is the right tool.

## Why it happens
Many 10-K PDFs are produced by legacy filing-agent software that writes slightly malformed stream dictionaries. Poppler's parser is strict about the endstream marker and warns loudly, but the text content is usually intact and recoverable. The warning is about spec compliance, not data loss, in most cases.

## Variant phrasings

Same failure and fix; some searchers phrase the query this way.

## Edge cases
- qpdf repair can change page object ordering; re-verify page numbers after repair.
- Some malformed streams contain the exhibits; text may look complete while exhibit pages are the ones dropped.
