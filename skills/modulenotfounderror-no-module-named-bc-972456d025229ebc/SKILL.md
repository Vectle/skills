Print which Python is running the failing code and check its version.

Install bcrypt through that interpreter by running python -m pip install bcrypt.

Run a one line import check with the same interpreter, importing bcrypt and printing its version attribute if present.

If you use a virtual environment, activate it first, or point your editor and server at that environment, then repeat steps 2 and 3 inside it.

Add bcrypt to your project requirements file so a fresh install includes it, then restart the app.
