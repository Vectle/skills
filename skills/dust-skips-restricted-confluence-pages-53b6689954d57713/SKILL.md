## TL;DR

If a Confluence page is missing from Dust, confirm it lives in a selected global space and has no view restrictions, because restricted content is excluded by design. Keep permission management with a single admin so the sync scope stays consistent.

## Steps

1. If a Confluence page is missing from Dust, confirm it lives in a selected global space and has no view restrictions, because restricted content is excluded by design. Keep permission management with a single admin so the sync scope stays consistent. After editing a page, allow up to an hour for the change to appear, Dust checks for updates hourly rather than continuously.
