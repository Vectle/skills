## TL;DR

A meta description is a 155-character ad for the click: say what the page delivers, who it is for, and the outcome, in plain words that mirror the query. Meta descriptions dont affect rankings, they affect CTR, so write them like ad copy, not summaries. For programmatic pages, build them from a template with the page's specific variables, never one generic description sitewide.

```text
how to write meta descriptions that earn clicks
```

## Use this when

- Pages rank well but CTR is below expectations
- GSC shows Google rewriting your descriptions (a sign yours are weak)
- Programmatic pages share one generic meta description
- You are launching new templates and want the snippet right from day one

## Not for this skill when

- The page doesnt rank (fix relevance first; nobody sees the snippet)
- You want ranking improvements (descriptions dont rank)
- The query intent is mismatched to the page (rewrite the page, not the snippet)

## Steps

1. Check what Google shows today. Search the target query and read the current snippet for your page. Expected: you know whether Google uses your description or rewrites it.

```
Search the query in an incognito window.
If the snippet isnt your description, yours is missing or unconvincing.
```

2. Write the pitch: deliverable plus audience plus outcome. One or two sentences, plain language, no keyword stuffing. Expected: a description that reads like the answer to "why click this".

```
Formula: what the page gives you + who it is for + what you will be able to do.
Example shape: "Fix [error] in [tool]: step-by-step with the exact commands, for [audience]."
```

3. Keep it under 155 characters. Longer descriptions get truncated with an ellipsis, which usually cuts the outcome, the most persuasive part. Expected: the full pitch visible in the SERP.

```
Hard limit: 155 characters including spaces.
Put the outcome early in case of truncation anyway.
```

4. Mirror the query terms naturally. Include the key terms from the target query once, in normal phrasing. Expected: bolded terms in the snippet that signal relevance to the searcher.

```
One natural placement beats three forced ones.
Match the searcher's words, not your internal jargon.
```

5. Template it for programmatic pages. Build the description from page variables: error string, tool name, audience. Expected: every generated page gets a unique, specific description.

```
Template: "Fix [error_string] in [tool_name]: [fix_summary] for [audience]."
Validate: uniqueness check across generated pages, length check per page.
```

## Variant phrasings

### Meta description best practices

Under 155 chars, pitch not summary, mirror the query, unique per page.

### Why does Google rewrite my meta description

Usually because yours is missing, duplicated across pages, or doesnt match the query; the fix is a better, query-aligned description.

### Meta descriptions for programmatic SEO

Template from page variables, validate uniqueness and length in the generator.

## Why it happens

The snippet is the only part of your page most searchers ever read, and they decide in about two seconds whether it matches their need. Generic or missing descriptions force Google to grab random page text, which rarely pitches the click. A good description works because it does the searcher's relevance check for them: same words they typed, clear deliverable, obvious outcome. Rankings get you seen; the description gets you chosen.

## Edge cases / pitfalls

- Google rewrites descriptions for roughly half of queries anyway; a good description raises the odds yours survives, it doesnt guarantee it.
- Dont duplicate the title in the description; the SERP shows both, so repetition wastes characters.
- Clickbait descriptions that the page doesnt deliver raise bounce rates and teach Google your snippets lie.
- For brand queries, the description matters less; for non-brand discovery queries, it matters most.
- Dates and prices in descriptions go stale; template them from live data or leave them out.
