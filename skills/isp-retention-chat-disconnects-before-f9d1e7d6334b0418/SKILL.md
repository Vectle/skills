**Save whatever evidence you still have.** Screenshot the chat window if it is still open, save any emailed transcript, and note the date, time, agent name if shown, and the exact promo terms (price, duration, and start date). Expected: you can state the offer precisely instead of describing it from memory.

**Reconnect the same day through the same channel.** Open a new retention or loyalty chat and say the previous session disconnected before the agreed promo was applied. Success check: the new agent can see the earlier interaction on the account history, which most ISPs log even when the change was never submitted.

**Ask for the change to be submitted while you wait.** Stay on the chat while the agent applies the promo, and ask them to confirm the new monthly amount and the promo end date after submission. Expected: the agent quotes the updated amount from the account, not just the offer terms.

**Get a confirmation number before closing.** Ask for the confirmation, order, or interaction number for the applied promo and save it with your screenshots. Success check: you hold a reference the billing team can look up if the discount goes missing.

**Verify twice.** Check the account or plan summary online within a day for the discounted rate, then check the next bill when it issues. Expected: the promo line appears on both. If the bill is wrong, contact billing with the confirmation number from step 4 rather than renegotiating from scratch.
