## TL;DR

Signature links are a phpBB and XenForo tradition, mostly absent on Discourse, and gated by post count or trust level almost everywhere that allows them. Never assume: check the signature settings page and the rules, because the platforms that allow signatures still restrict them for new accounts. Where signatures are banned, a filled-in profile website field is the fallback.

```text
forum signature links: which platforms allow them
```

## Use this when

- You are planning signature strategy across multiple forum platforms
- You want to know if a venue supports signature links before investing
- A signature link you set isnt showing up

## Not for this skill when

- You want to put links in signatures where the rules forbid them
- You need help writing the signature copy itself
- The forum is a custom build (check its settings directly)

## Steps

1. Check the platform. phpBB and XenForo have signature features by default; Discourse has no signatures at all (it shows user cards instead); NodeBB and Flarum vary by plugin. Expected: you know whether signatures exist on the venue.
2. Find the signature settings. Look under User Control Panel or profile preferences for a signature editor. Expected: either a signature box or nothing.
3. Check the gating. Most forums require a minimum post count or trust level before signatures render, and some require moderator approval. Expected: you know when your signature will actually appear.
4. Read the signature rules. Link counts, image bans, and length limits are usually spelled out; one or two links is the common cap. Expected: a compliant signature, not a deleted one.
5. Set it and verify logged out. Save the signature, then view one of your posts without logging in. Expected: the signature renders for guests, which is most of your audience.
6. Track it per venue. Note allow or deny plus the gating threshold in your venue list. Expected: no surprises when you revisit.

## Variant phrasings

### do Discourse forums have signatures

No, Discourse deliberately omits signatures; use the profile fields and user card instead.

### phpBB signature not showing up

Usually a post-count threshold or a per-usergroup permission; check both.

### forum signature link limits

One to two links is typical where allowed; more reads as spam and gets edited by mods.

## Why it happens

Signatures are a legacy forum feature from the days when every post carried a footer. Modern platforms like Discourse dropped them as clutter, while older platforms kept them but layered anti-spam gating on top, so the landscape is inconsistent.

## Edge cases

- Some forums show signatures only to logged-in members; guests see nothing, which kills most of the value.
- Admins can disable signatures forum-wide even on platforms that support them; the settings page may exist but do nothing.
- Signature links are almost always nofollowed; treat them as traffic and credibility, not SEO.
- Changing your signature later updates it on all past posts, which is convenient but also means a rule change can retroactively break you.
