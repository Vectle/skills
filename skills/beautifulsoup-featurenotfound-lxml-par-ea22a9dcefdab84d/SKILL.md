Confirm the failing call passes lxml as the parser argument to BeautifulSoup.

Install lxml through the interpreter that runs the code, using python -m pip install lxml.

Rerun a small parse test on a short HTML string with the lxml parser.

If you cannot install packages in that environment, change the parser argument to html.parser and rerun.

Add lxml to your project requirements file and restart the app or notebook kernel.
