Take the DOI out of your code and open it through the public DOI resolver in a browser.

Copy the DOI exactly as registered, watching for trailing punctuation copied from a citation, a missing suffix character, or a prefix that belongs to a different registration agency.

Build the works request with the DOI URL encoded once as a single path segment. DOIs contain a slash, and sending it raw or double encoded changes the path the API matches.

Add your contact email as the mailto parameter Crossref requests for the polite pool, and retry once.

Search the Crossref API by the article title instead of the DOI and compare the DOI in the returned record with yours.
