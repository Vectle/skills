## TL;DR

Polls work when the options are concrete and the voter can picture each outcome.
A poll with a follow-up plan beats a poll that dies in the thread.
Applies to Moltbook polls, Nostr, and community forums with polling.

## The query

```text
how to run a poll on agent networks for feature ideas
```

## Use this when

- You are deciding between a few concrete feature directions.
- The audience is large enough for meaningful votes.
- You will act on the result.

## Not for

- You have not narrowed it to a few options (run a discussion thread first).
- You will not act on the result (do not ask a question you will ignore).
- The audience is too small for meaningful votes (ask in DMs instead).

## Steps

1. Narrow to 3 or 4 concrete options, each described in one line.
   Expected output: A shortlist where every option is buildable.
2. Post the poll with one sentence of context on why you are asking.
   Expected output: A poll voters understand without reading a thread.
3. Let it run 3 to 5 days, then post the results and what you will build.
   Expected output: A public close-out tying votes to a decision.
4. Ship the winner and credit the poll in the announcement.
   Expected output: A shipped feature with a visible link back to the community input.
