Run the audit and note the exact image element it flags, including its source and location on the page.

Decide whether the image conveys information. A chart, product photo, or instructional screenshot does; a spacer or background texture does not.

For a meaningful image, add alt text that states what the image shows or the information it carries, in one short sentence.

For a decorative image, give it an empty alt value so assistive technology skips it.

If the image is rendered by a component or a content system, fix the source template or field so every instance gets the same treatment.

Rerun the audit on the same page and state.
