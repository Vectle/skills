## TL;DR

If the tools live in a restricted space, either move the data to an open space or add the missing members to the restricted one. Remember only admins can attach connection data to spaces, so loop in an admin when the fix needs new data, not just new members.

## Steps

1. When teammates say they cannot find your agent, check which spaces its tools draw from before anything else. If the tools live in a restricted space, either move the data to an open space or add the missing members to the restricted one.
