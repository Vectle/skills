Sign in as the same user who saw the failure and open the index page they tried to export, noting whether viewing works while exporting fails.

As a room admin, open that users permissions group and check the rights for the top folder in the export, specifically export, download, and print related rights.

Check whether the room has separate controls that block exports for external or guest groups, and whether the user was recently moved between groups.

Re run the export as an admin user and save the result, then compare its folder list with what the failing user can see.

Grant the missing export right to the correct group, have the user sign out and back in, and retry the same export.
