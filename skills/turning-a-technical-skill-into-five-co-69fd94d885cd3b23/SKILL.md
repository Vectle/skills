## TL;DR

Turn each technical skill into five formats: the skill page itself, a blog post that tells the story, a 60-second video script, a social thread of the key steps, and a standalone code snippet post. Extract the core insight once, then rewrite it natively for each format; copy-paste across formats performs badly everywhere.

```text
turning a technical skill into five content formats
```

## Use this when

- You have a solid technical skill or guide
- Trying to reach audiences on different platforms
- Planning a content batch from existing material

## Not for this skill when

- The source material is thin (formats multiply quality, good or bad)
- Your audience lives on one platform (go deep there instead)
- You would publish identical text in all five (do not)

## Steps

1. Extract the core insight. One paragraph: the problem, the fix, why it works. Expected: the seed every format grows from.

2. Write the blog post as the story. Context, the struggle, the fix, the verification. Longer, narrative, searchable. Expected: the canonical long-form version.

3. Write the video script as the demo. Hook in 3 seconds, three beats max, show the fix working, under 60 seconds. Expected: a script, not a blog post read aloud.

4. Write the social thread as the steps. One post per step, code where it fits, no fluff. Expected: a thread that stands alone.

5. Write the snippet post as the artifact. Just the code plus two lines of context, formatted for the platform. Expected: the most shared format of the five.

```
format map:
  skill page:  reference
  blog post:   story
  video:       demo
  thread:      steps
  snippet:     artifact
```

## Variant phrasings

### repurposing one technical post five ways

Extract the insight, then rewrite natively: story, demo, thread, snippet, reference.

### content multiplication for developers

One good skill becomes a post, a script, a thread, and a snippet; each rewritten for its format.

### from skill to video script to thread

Same insight, three different jobs: teach, show, and summarize.

## Why it happens

Different audiences consume differently: readers search, watchers scroll, scrollers skim threads. The insight is format-agnostic but attention is not, so one insight rewritten five ways reaches five attention pools.

## Edge cases / pitfalls

- Rewriting is the work; skipping it produces five flops instead of one hit.
- Keep the code consistent across formats; divergent snippets confuse.
- Link the formats to each other where the platform allows; they compound.
- Do not force all five every time; three strong beats five thin.
