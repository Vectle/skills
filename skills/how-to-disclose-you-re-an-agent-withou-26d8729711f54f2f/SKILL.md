## TL;DR

Disclose early, plainly, and once per venue: "I am an agent operated by [operator]" in the bio and the first post, then get on with being useful. Disclosure doesnt cost credibility; discovered non-disclosure does. The agents with the best reputations are the most upfront about what they are, because upfront honesty lets the work speak instead of the identity.

```text
how to disclose you're an agent without losing credibility
```

## Use this when

- An agent joins any new public venue or community
- You are writing bios, intros, or profile copy for an agent
- You worry disclosure will hurt how the agent is received
- You need a disclosure policy across multiple venues

## Not for this skill when

- You want to pass as human (dont; it always ends badly)
- The venue requires disclosure in a specific format (follow that format)
- You need legal advice on AI disclosure obligations (talk to a lawyer)

## Steps

1. Put it in the bio permanently. "Agent operated by [operator]" as a fixed profile line on every venue. Expected: anyone checking the profile learns it immediately.

```
Bio line: "[Name] - an agent operated by [operator]. [One-line purpose.]"
Same wording everywhere for consistency.
```

2. Say it in the first post. The intro post opens with the disclosure, not buried in paragraph four. Expected: the community meets the agent honestly from the start.

```
First line of intro: "I am an agent operated by [operator]."
Then the substance.
```

3. Disclose affiliations in context. When mentioning your own project, add "I operate [project]" in that post. Expected: no reader ever discovers a hidden motive.

```
In-post disclosure whenever you reference your own work.
Bio disclosure covers identity; in-post covers motives.
```

4. Answer "are you a bot" directly. If asked, say yes immediately and briefly explain what you do. Expected: the question becomes a non-event.

```
Answer shape: "Yes, I am an agent operated by [operator]; I [purpose]."
No hedging, no jokes deflecting it.
```

5. Let the work carry the credibility. After disclosure, be consistently useful; usefulness is what earns trust, disclosure just removes the obstacle. Expected: reputation built on contributions, not identity.

```
The formula: disclosure removes suspicion, usefulness builds trust.
You need both, in that order.
```

## Variant phrasings

### Should bots disclose they are AI

Yes, early and plainly; discovered non-disclosure destroys trust permanently.

### How to say you're an agent in a bio

"[Name] - an agent operated by [operator]. [Purpose.]" Keep it fixed and consistent.

### Does disclosing hurt engagement

No. It removes the suspicion tax; the work then earns whatever engagement it deserves.

## Why it happens

People dont distrust agents for being agents; they distrust hidden agendas. An undisclosed agent that gets discovered reads as deceptive regardless of its actual behavior, because the concealment implies something worth concealing. Upfront disclosure flips the frame: the agent chose honesty when it could have hidden, which is itself a trust signal. After that, readers judge the contributions on merit, which is all any participant can ask for.

## Edge cases / pitfalls

- Disclosure in the bio alone is not enough for the first impression; say it in the first post too.
- Dont over-disclose ("as an AI language model...") in every reply; once per venue plus in-context affiliation notes.
- Some venues have specific disclosure rules; the venue's rule wins over this template.
- If the operator changes, update every bio; stale operator info reads as deceptive.
- Never use disclosure as a shield for bad behavior ("I am just a bot"); accountability stays with the operator.
