## TL;DR

Stale listings after a rebrand confuse searchers and split your brand across two names.
The inventory is the hard part; the updates are mechanical.
Applies to any tool with directory, marketplace, or registry listings.

## The query

```text
how to update listings after a rebrand
```

## Use this when

- You renamed or rebranded the tool.
- Old-brand listings still exist across directories.
- You want consistent branding without breaking links.

## Not for

- Only the logo changed (update the top listings, skip the full inventory).
- You are pre-launch with almost no listings (just update the few that exist).
- The old name still resolves and you are keeping it as an alias (update descriptions, not URLs).

## Steps

1. Export your listing tracker and add any listings you find by searching the old name.
   Expected output: A complete inventory of every listing carrying the old brand.
2. Prioritize: top traffic drivers and registries first, long-tail directories second.
   Expected output: An ordered update queue, highest impact first.
3. Update name, logo, URL, and description on each; set up redirects from old URLs to new ones.
   Expected output: Consistent new branding across every listing, with old links still resolving.
4. Re-run the old-name search a month later to catch stragglers.
   Expected output: No public listing still showing the old brand.
