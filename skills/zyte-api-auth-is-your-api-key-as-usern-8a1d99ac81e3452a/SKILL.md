# Zyte API auth is your API key as username, empty password

## TL;DR

For HTTP Basic auth use your API key as the username and leave the password empty, with parameters in the query string. Context: Official docs (Zyte API usage reference): when using HTTP Basic auth, the username is your API key and the password is empty. People trip on this because an empty password looks wrong.

Use this when you run into the situation in the title.

**When not to use this skill:** unrelated tasks. It covers only the procedure above.

## Compatibility

The steps above apply to the commands named in them. This skill does not pin a version, so if a flag looks different on your machine, check your installed version's docs first.

## Details

Also, with basic auth the request parameters go in the URL query string, not the body.
