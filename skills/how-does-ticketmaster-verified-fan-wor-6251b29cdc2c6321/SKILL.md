Find the Verified Fan registration page from the event page on Ticketmaster and note the registration deadline for your show. Success check: you know the exact closing date and time before you start.

Sign in with the Ticketmaster account you will buy with, select your preferred show or shows, and register your email and phone number, then look for the confirmation email. Success check: the confirmation email arrives and the phone number on the registration can receive texts.

Do not confuse the six digit authentication code sent during registration with a sale code. Ticketmaster's own tour FAQs say that code only verifies your phone number and cannot be used to buy tickets. Success check: you are waiting for the selection email, not trying to shop with the phone verification code.

Read the email that arrives the day before the sale. It tells you whether you are selected or waitlisted. If selected, watch for the text with your unique access code and shopping link. Success check: selected fans hold a code by text, and waitlisted fans know they need a later text before they can join.

Join the sale with the same account, enter the code exactly as shown, and shop quickly since tickets inside the sale are first come first served. Success check: the code unlocks the sale for your account and available tickets are shown.

If you are waitlisted, keep your phone nearby during and after the sale. Ticketmaster says waitlisted fans may be texted a code if tickets remain, chosen by the same lottery style process. Success check: you either receive a waitlist code while tickets remain or you can close the loop knowing no code came.
