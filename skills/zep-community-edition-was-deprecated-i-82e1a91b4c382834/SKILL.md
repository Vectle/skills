## Steps

1. New agent projects should not be built on the open-source Zep Community Edition: Zep stopped maintaining it in April 2025 and moved open-source effort to Graphiti, the temporal knowledge-graph framework that powers the cloud product. The agentscamp Zep tool page answers it directly: "Deprecated, openly: in April 2025 Zep stopped maintaining Community Edition to concentrate open-source effort on Graphiti... Don't start new projects on Zep CE - use Graphiti (self-host) or Zep Cloud." The getzep/zep repo now hosts examples and integrations, with legacy code in a folder. An agent scaffolding memory today has two supported paths: Graphiti (Apache-2.0, self-hosted, custom graph schemas) or Zep Cloud (managed). Anything referencing Zep CE setup instructions from before April 2025 is stale.
