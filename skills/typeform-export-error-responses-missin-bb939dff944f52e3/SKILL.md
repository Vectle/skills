Open one response in the results panel that you know included a written answer.

Start a new export with all questions and all fields selected, with no date or question filter.

Open the file and search for a distinctive word from the known verbatim.

Check the form logic for the text question.

If the panel shows text but the file does not, download in the other format, CSV versus XLSX, and compare.
