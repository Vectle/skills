Open the same TSDR status page in a regular browser with the same serial or registration number.

Check the USPTO systems status notices for TSDR maintenance or outages.

If you are scripting the check, set a normal browser user agent header and include the referer header for the TSDR site.

Add pacing of several seconds between lookups and stop parallel requests.

Cache each successful status result locally so repeat checks do not re-hit TSDR.
