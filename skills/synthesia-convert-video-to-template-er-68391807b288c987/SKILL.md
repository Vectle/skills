## Why it happens

If Synthesia refuses to generate with 'Convert video to template', the video contains API variables (personalized placeholders). Per the Synthesia knowledge base, API variables are only compatible with templates, so the video must be converted to a template before generation. This is the designed flow for personalized videos at scale: build the template once with variable slots, then generate per recipient with variable values.
