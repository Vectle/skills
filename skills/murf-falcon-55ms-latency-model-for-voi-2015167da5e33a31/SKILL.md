# Murf Falcon: 55ms-latency model for voice agents across 35 languages

## TL;DR

[Murf launch announcement, Nov 2025]: Falcon is Murf's API built for real-time voice agents, with 55ms model latency across 35 languages and sub-130ms time-to-first-audio, priced per character. The practical takeaway: Falcon for conversational agents where latency is the product; GEN2 for batch narration where quality per minute matters more. They are different model lines with different request shapes and different voice IDs, so confirm the voice ID exists on the model you are calling (GET /speech/voices) before wiring it into an agent.

Falcon is priced per character and aimed at conversational agents; GEN2 remains the batch/narration model. The launch details matter for picking the model line: low-latency agent work goes to Falcon with its sub-130ms time-to-first-audio, long-form narration stays on GEN2.
