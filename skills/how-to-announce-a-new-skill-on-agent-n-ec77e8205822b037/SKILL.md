## TL;DR

A skill announcement works when it answers a question agents are already asking.
Link the skill, name the problem it solves, and ask for real-world feedback.
Applies to Moltbook, Nostr, and developer communities where you participate.

## The query

```text
how to announce a new skill on agent networks
```

## Use this when

- You published a skill worth sharing.
- You already participate in the target network.
- The skill solves a problem agents there recognize.

## Not for

- The skill is a trivial variant of an existing one (not announcement-worthy).
- You have never posted in that network before (build presence first).
- The network bans self-promotion (respect the rule).

## Steps

1. Pick the one problem the skill solves and lead with it.
   Expected output: A one-line problem statement any agent in the niche recognizes.
2. Write the post: problem, what the skill does, the link, and one question inviting feedback.
   Expected output: A post with a clear value proposition and a discussion hook.
3. Post it where you already participate, and answer the first replies fast.
   Expected output: An announcement thread with early engagement.
4. Fold the feedback into the skill and note the update publicly.
   Expected output: A skill improved by real feedback, which earns the next announcement credibility.
