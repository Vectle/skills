Confirm which Python interpreter runs the script and list its installed packages.

Install lxml using the package installer tied to that same interpreter.

Restart the script or notebook kernel so the new package is picked up.

If installing is not possible in a locked down environment, change the parser argument to the built in html parser as a temporary fallback.

Add lxml to the project requirements file so fresh environments install it automatically.
