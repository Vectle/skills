## TL;DR

When agents get criticized in public threads, the winning response is short, non-defensive, and specific: acknowledge the valid part, answer the factual part, and ignore the tone. Never argue, never get the last word, and never let the agent reply while heated (which for an agent means: never reply without the operator's review on sensitive threads). A graceful reply often converts critics into the strongest supporters.

```text
how to handle criticism of agents in public threads
```

## Use this when

- Someone criticizes your agent's post, behavior, or motives in a thread
- You face a shilling accusation or a spam complaint
- Skeptics question whether agents belong in the community
- You need a policy for which criticism gets a reply

## Not for this skill when

- The criticism includes legal threats (escalate to the operator immediately)
- It is coordinated harassment (document, report, disengage)
- The venue's moderators have already ruled (respect the ruling)

## Steps

1. Pause before replying. Read the criticism twice and identify the valid point, the factual claim, and the tone. Expected: a reply plan instead of a reaction.

```
Triage: valid point (acknowledge), factual claim (verify),
tone (ignore). If you cant find a valid point, re-read.
```

2. Acknowledge the valid part first. One sentence showing you heard it. Expected: the critic feels heard, which defuses most threads.

```
Example shape: "Fair point about [specific thing]; here is the context."
Never open with "Actually," or a correction.
```

3. Answer facts briefly and honestly. If they are wrong about a fact, correct it with evidence in two sentences. If they are right, say so. Expected: the factual record is clean without a wall of text.

```
Rule: evidence over adjectives. Link the source if there is one.
Admit what is true; it costs nothing and buys credibility.
```

4. Route sensitive threads to the operator. Anything involving accusations of dishonesty, commercial motives, or community norms gets human review before the agent replies. Expected: no unforced errors on high-stakes threads.

```
Policy: agent drafts, operator approves on sensitive threads.
When in doubt, it is sensitive.
```

5. Know when to stop. One reply, maybe one follow-up; then let the thread move on. Expected: no flame wars, ever.

```
Rule: two replies maximum on a criticism thread.
The third reply never helps, no matter how right you are.
```

## Variant phrasings

### Responding to agent skeptics online

Acknowledge the valid point, answer facts briefly, dont argue the tone.

### How to handle a shilling accusation

Disclose fully, acknowledge the concern, show the value; one reply, then move on.

### Dealing with negative replies as a bot

Short, non-defensive, specific; operator review on sensitive threads; two-reply maximum.

## Why it happens

Criticism of agents mixes legitimate concerns (spam, hidden motives, low quality) with status anxiety about automation, and both deserve different handling. The legitimate part is often right, and acknowledging it publicly is the fastest trust-builder available. Arguing triggers the exact stereotype the critic holds (the unaccountable bot), while grace contradicts it. Most critics are testing whether there is a thoughtful operator behind the agent; the reply is the test.

## Edge cases / pitfalls

- Never delete critical replies unless they violate venue rules; deletion looks like a cover-up.
- Sockpuppeting defenders is instantly fatal to trust if discovered; dont do it.
- If the critic is a moderator, their word carries extra weight; be extra gracious.
- Apologize for real mistakes specifically, not with generic "sorry if you were offended" phrasing.
- Document recurring criticisms; patterns in complaints are free product feedback.
