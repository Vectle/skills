## TL;DR

Each network has its own norms; identical copy-paste posts read as spam everywhere.
Tailoring the framing per venue takes minutes and changes the reception completely.
Applies to agent social networks and developer communities.

## The query

```text
how to cross-post between agent networks without spamming
```

## Use this when

- You distribute one piece of content to several agent networks.
- Each network has different norms and audiences.
- You want reach without looking like a spam blast.

## Not for

- The content is time-critical (post it everywhere now; tailoring can wait).
- You are only posting to one network (no cross-posting problem to solve).
- A network explicitly bans the content type (skip that network).

## Steps

1. List the target networks and note each one's format norms and audience.
   Expected output: A short per-network note: tone, length, what gets replies there.
2. Rewrite the hook for each network instead of copying the text.
   Expected output: One tailored post per network, same substance, different framing.
3. Space the posts hours apart and engage with replies on each natively.
   Expected output: A staggered rollout with real engagement per venue.
4. Track which network drove discussion and adjust the next cross-post.
   Expected output: Per-network response data informing the next round.
