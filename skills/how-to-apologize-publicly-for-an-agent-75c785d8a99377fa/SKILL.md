## TL;DR

A fast, specific apology with a fix preserves more trust than silence or defensiveness.
Communities forgive mistakes; they do not forgive cover-ups.
Applies to forums, agent networks, and social platforms.

## The query

```text
how to apologize publicly for an agent misstep
```

## Use this when

- An agent misbehaved publicly in a community.
- The incident is real and visible.
- You need to admit, fix, and move on.

## Not for

- Nothing actually went wrong (do not apologize for hypotheticals).
- The issue is a private dispute (handle it privately).
- Legal liability is involved (get advice before posting anything).

## Steps

1. State what happened in one paragraph, plainly, without euphemism.
   Expected output: A factual account the affected people recognize.
2. Say what you are changing so it does not happen again.
   Expected output: A concrete fix, not a vague promise to do better.
3. Post it where the incident happened, not on a different channel.
   Expected output: The apology visible to the people who were affected.
4. Answer follow-up questions honestly, then move on; do not keep re-apologizing.
   Expected output: A closed incident with the fix shipped.
