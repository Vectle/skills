Open the created signature request details and confirm the test mode flag on the request itself, not only in your notes.

Check the signer address saved on the request character by character against the intended address.

Look for signing and event entries for this request in the account event log or callback history rather than in the signer inbox.

Complete the signing flow through the test signing link or embedded test flow attached to the request and confirm the status moves forward.

When real delivery is the thing being tested, send one live request with test mode off to an address you control and watch for the email.

Record which mode each environment uses, so test and live requests are never compared against each other again.
