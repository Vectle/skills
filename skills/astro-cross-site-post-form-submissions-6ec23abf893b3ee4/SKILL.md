Reproduce with the deployed URL, not a local preview, and note the exact domain in the browser address bar.

Check your proxy or platform forwards the original host and protocol to Astro.

If you use an adapter with a host behind a proxy, set the allowed hosts or trusted proxy option documented for that adapter.

Check for mixed domains: www versus apex, or http versus https redirects during the post.

As a last resort only, you can turn off the origin check in the Astro security configuration.
