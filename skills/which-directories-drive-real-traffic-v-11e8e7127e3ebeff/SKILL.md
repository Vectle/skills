## TL;DR

Find which directories drive real traffic by tagging every listing URL with UTM parameters and watching referral reports for 60 to 90 days. Most directories will show near-zero visits; a few will drive actual signups. Put maintenance effort into the few, keep the rest as passive SEO, and stop submitting to directories that deliver neither.

```text
which directories drive real traffic vs SEO only
```

## Use this when

- Deciding where to spend submission effort
- Auditing an existing set of listings
- Reporting on directory ROI

## Not for this skill when

- Listings are less than a month old (too early to judge)
- You have no analytics on the landing pages (fix that first)
- Every directory is free and effortless (then it hardly matters)

## Steps

1. Tag every listing URL with UTM parameters. Source is the directory name, medium is directory, campaign is the batch. Expected: every click from a listing is attributable.

```
tagged URL pattern:
  https://example.com/?utm_source=[directory]&utm_medium=directory&utm_campaign=[batch]
```

2. Wait 60 to 90 days. Directory traffic builds slowly as pages get indexed and browsed. Expected: enough data to separate signal from noise.

3. Pull referral and UTM reports. Rank directories by sessions, then by signups or conversions, not just clicks. Expected: a clear top few and a long tail of zeros.

4. Classify each directory. Traffic drivers get maintenance and updates; SEO-only ones stay as-is; neither-traffic-nor-SEO ones get no more effort. Expected: three buckets with names in them.

5. Reallocate. Update the winners quarterly, leave the SEO bucket alone, and skip the losers in future batches. Expected: effort follows evidence.

## Variant phrasings

### do directory listings drive traffic

A few do; tag URLs with UTM, wait 60 to 90 days, and let the referral data rank them.

### measuring directory ROI

Sessions and signups per directory via UTM; classify into traffic, SEO-only, and neither.

### which directories are worth maintaining

The ones with real referral conversions. The rest are passive listings.

## Why it happens

Directory traffic follows a power law: a handful of well-trafficked, well-matched directories send real users, while most are scraped, parked, or unbrowsed. Without measurement, effort spreads evenly across all of them, which means it is wasted on most of them.

## Edge cases / pitfalls

- Nofollow links can still drive traffic; judge by visits, not link attributes.
- Seasonal or launch spikes distort the data; compare equivalent periods.
- Some directories drive branded search instead of direct clicks; check search consoles too.
- Do not kill an SEO-only listing that ranks; passive value is still value.
