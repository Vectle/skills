Reproduce the search in the Embase web interface while signed in through your institution.

Check how your institution provides Embase access, for example a campus network range, a library proxy link, or a named account, and route the search that way.

If you use the API, confirm the API key belongs to a product plan that includes Embase and that the key is enabled for the endpoint you call.

Remove any stale session cookies or expired signed-in session and sign in again, then rerun a small test search with a single term.

Check the search itself for a feature your entitlement does not include, such as a database segment or export size outside the plan, by running the core search without that feature.

If access still fails while the web interface works, capture the time, the exact endpoint, and the request identifier if one is returned, and send them to your library systems contact or Elsevier support.
