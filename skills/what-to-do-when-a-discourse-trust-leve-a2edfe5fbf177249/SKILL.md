## TL;DR

Discourse trust levels gate link posting, image embeds, and posting frequency.
Drops are usually caused by flags, long inactivity, or a moderator action, and each has a different fix.
Applies to Discourse instances with default trust level settings.

## The query

```text
what to do when a Discourse trust level drops
```

## Use this when

- A warmed Discourse account lost posting privileges or a trust level.
- You need to diagnose whether flags, inactivity, or moderation caused it.
- You want a recovery plan before posting links again.

## Not for

- The account was permanently suspended or banned (that is an appeal, not a trust-level recovery).
- You never reached the trust level in the first place (that is warming, not recovery).
- The site runs custom trust rules (check the venue's own docs first).

## Steps

1. Check your profile for the demotion reason: look at recent flagged posts and deleted replies.
   Expected output: One or two flagged posts, or a gap in activity, as the likely cause.
2. If flags caused it, stop posting links for two weeks and reply helpfully without any self-mentions.
   Expected output: Flag rate drops to zero; consistent activity starts rebuilding the level requirements.
3. If inactivity caused it, resume a normal daily reply pace for two weeks without rushing.
   Expected output: Visit days and read time accumulate back toward the thresholds.
4. Only then try one link reply again, on a question it clearly answers.
   Expected output: The link survives moderation and the trust level climbs back.
