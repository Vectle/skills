## TL;DR
Google Workspace offboarding means transferring the user's Drive data, handling email aliases and delegation, then removing the license. Do the data transfer before deleting anything.

## The query
```text
google workspace license reassignment during offboarding
```

## Use this when
- employee offboarding in Google Workspace
- reclaiming licenses from departed users
- manager needs the ex-employee's Drive files

## Not for
- buying more licenses (different task)
- deleting the user before data transfer
- personal Gmail accounts (not yours to touch)

## Steps
1. Transfer Drive and Docs ownership to the manager or a successor. Expected output: data transfer initiated
2. Set up email delegation or forwarding for the transition period per policy. Expected output: mail handled
3. Handle aliases: move business aliases to someone active. Expected output: aliases preserved
4. Remove the Google Workspace license from the user. Expected output: license reclaimed
5. Suspend or delete the account per your retention policy. Expected output: account state correct
6. Document the steps in the offboarding ticket. Expected output: audit trail complete
